# 💝 Will You Be My Valentine?

A fun and interactive Valentine's Day webpage where the "No" button runs away from your cursor (or finger on mobile)!

## ✨ Features

- 🎨 Beautiful gradient design with floating hearts animation
- 🖱️ **Desktop**: "No" button moves away from your mouse cursor in 2D space
- 📱 **Mobile**: "No" button flees from your touch
- 💕 Only way to respond is "Yes!"
- 🎉 Celebration animation when "Yes" is clicked
- 📱 Fully responsive and works on all devices

## 🚀 Demo

Simply open `a.html` in your browser to see it in action!

## 🎮 How It Works

- The "No" button detects when your cursor (or finger) gets within 150px
- It calculates the direction vector from your input to the button
- Moves away in the exact opposite direction
- Bounces off the edges to stay within bounds
- Uses both mouse events (desktop) and touch events (mobile)

## 💻 Technologies Used

- Pure HTML5
- CSS3 (Gradients, Animations, Flexbox)
- Vanilla JavaScript (No frameworks!)
